# Pratik Jadhav — Portfolio

A cinematic, responsive developer portfolio built with React, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Before deployment

The resume did not contain actual GitHub/LinkedIn/project URLs, so the social buttons are intentionally placeholders (`#`). Replace those href values in `src/main.tsx` when you have the links.

The portfolio uses the email from the supplied resume: `jadhavpratik6543@gmail.com`.
